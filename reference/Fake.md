# Datasets generated from ARD models

Some artificial datasets simulated from various ARD models.

## Usage

``` r
Fake_maltiel_RD
```

## Format

Unless stated otherwise below all datasets are data frames with
respondents in rows and subpopulations in columns.

## Details

- `Fake_maltiel_RD` is sampled from Maltiel et al (2015) Random Degree
  model assuming 1000 respondents and 3 subpopulations.

## References

Maltiel, R., Raftery, A. E., McCormick, T. H., & Baraff, A. J. (2015).
Estimating Population Size Using the Network Scale Up Method. The Annals
of Applied Statistics, 9(3), 1247–1277.
<https://doi.org/10.1214/15-AOAS827>
