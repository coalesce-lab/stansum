# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

`stansum` is an R package wrapping precompiled Stan models for Aggregated Relational Data (ARD) / Network Scale-Up Method (NSUM) degree estimation: models by Zheng et al (2006), Maltiel et al (2015), and Baum & Marsden (2023). Stan models are embedded via the **instantiate** package and sampled with **cmdstanr**. Requires a working CmdStan toolchain (`cmdstanr::install_cmdstan()`); cmdstanr comes from the extra repository `https://mc-stan.org/r-packages/`.

## Commands

All from the package root. Installing compiles every model in `src/stan/` with CmdStan, so `R CMD INSTALL` / `devtools::install()` is slow (minutes); `devtools::load_all()` does **not** compile models, so anything that calls `get_model()` needs a proper install first.

```r
devtools::document()                 # regenerate NAMESPACE + man/ (never edit those by hand)
devtools::install()                  # compiles Stan models into bin/stan/ of the installed package
devtools::test()                     # all tests
devtools::test(filter = "zheng-bem-count")   # single test file (tests/testthat/test-<filter>.R)
devtools::check()                    # R CMD check (CI runs this with --as-cran)
rmarkdown::render("README.Rmd")      # README.md is generated; edit README.Rmd only
source("vignettes/precompile.R")     # regenerate the precomputed vignette (see below)
pkgdown::build_site()                # website
```

Shell equivalents: `R CMD INSTALL .`, `R CMD build . && R CMD check --as-cran stansum_*.tar.gz`.

Model-fitting tests are wrapped in `skip_on_cran()`; run them locally with the package installed.

## Architecture

**Stan sources → compiled binaries.** `src/stan/*.stan` are the models. `src/install.libs.R` (from the instantiate template) copies them to `bin/stan/` in the installed package and compiles them there at install time; `src/Makevars` is intentionally empty and the `cleanup` scripts remove `bin/`. `list_models()` simply lists `bin/stan/*.stan` of the installed package, and `get_model(name)` returns a `CmdStanModel` via `instantiate::stan_package_model()`. Hence the R-level name of a model **is** the `.stan` file basename (e.g. `"ZhengBEM_count"`).

**One R wrapper per model.** Each exported `<author>_<model>_<response>()` function (e.g. `zheng_bem_count()`, `maltiel_tbm_count()`) is a thin shim: it calls `get_model()`, assembles the `data` list from its arguments, and returns `mod$sample(data = d, ...)` (a `CmdStanMCMC`). Wrappers for one model family share a single roxygen page (`@rdname zheng_bem`, etc.) in one file (`R/zheng_bem.R`, `R/maltiel_rdm.R`, ...), and all pull shared `@param ...`/`@details`/`@returns` text from the template `man-roxygen/wrapped-stan-model.R` via `@template wrapped-stan-model`. Adding a model = new `.stan` file + wrapper following this pattern + `devtools::document()`.

Naming convention across `src/stan/`: `<Author><Model>_<response>.stan` where response ∈ `count`, `dichotomous`, `trichotomous`. `bernoulli.stan` / `test_model()` exist only as a smoke test of the build.

**Precomputed vignette.** `vignettes/stansum.Rmd.orig` is the source; `vignettes/stansum.Rmd` is its knitted output committed to git (so `R CMD build` never samples). Edit the `.orig`, then `source("vignettes/precompile.R")` with the package installed and CmdStan available. Both `.orig` and `precompile.R` are in `.Rbuildignore`.

**Data.** `data/Fake_maltiel_RD.rda` (1000 × 3 simulated ARD) is generated by `data-raw/Fake_maltiel_RD.R`; tests and examples use it as the standard input.

## CI notes

`.github/workflows/R-CMD-check.yaml` sets `_R_CHECK_COMPILATION_FLAGS_KNOWN_` to whitelist the `-Wno-*` flags CmdStan's makefiles inject when models compile at install time; without it `--as-cran` fails on compilation-flag warnings. Keep that in sync if CmdStan starts emitting new flags.
